Create JS
===

-------------
## GENERAL ##
-------------

**https://parceljs.org/getting-started/webapp**
```shell
npm create parcel vanilla my-parcel-app
```

**https://vite.dev**
```shell
npm create vite@latest my-app -- --template vanilla
yarn create vite
deno init --npm vite
```

--------------
## SPECIFIC ##
--------------

**https://angular.dev**
```shell
npm install -g @angular/cli && ng new my-app
```

**https://nestjs.com** Node framework
```shell
npm install -g @nestjs/cli && nest new my-api
```

**https://nextjs.org** React framework
```shell
npx create-next-app@latest
yarn create next-app
```

**https://nuxt.com** Vue framework
```shell
npm create nuxt@latest
```

**https://preactjs.com**
```shell
npm init preact
npm create vite@latest my-preact-app -- --template preact
```

**https://react.dev/learn/build-a-react-app-from-scratch**
```shell
npm create vite@latest my-app -- --template react-ts
npx create-react-router@latest
```

**https://solidjs.com**
```shell
npx degit solidjs/templates/js my-app
npm create vite@latest my-solid-app -- --template solid
```

**https://svelte.dev**
```shell
npx sv create my-app
```

**https://vuejs.org**
```shell
npm create vue@latest
```

## SERVER ##
------------

**https://expressjs.com/en/5x/starter/installing**
```shell
mkdir my-server && cd my-server && npm init -y && npm install express && \
   npm install -D typescript @types/express @types/node
```
